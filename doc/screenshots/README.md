# Screenshots & Media Assets

This directory holds screenshots and showcase assets for the **Sudoku+** repository and documentation.

## Suggested Screenshots

1. **`gameplay_board.png`** &mdash; The active game grid showing high-contrast e-ink cells, pencil notes, and the input number bar.
2. **`progressive_hint.png`** &mdash; A hint step popup explaining a logical technique (e.g. Skyscraper or Naked Triple) with highlighted candidate cells.
3. **`stats_dashboard.png`** &mdash; The player statistics dashboard showing streaks, completion times, and most-missed techniques.
4. **`game_history.png`** &mdash; The browsable game log screen with the miniature board preview and "Play again" replay action.

## Recommended Capture Settings

- **Source**: KOReader Emulator or an actual e-reader device (e.g. Kobo Aura One / Clara 2E / Libra 2).
- **Resolution**: 1404x1872 or 1072x1448 (grayscale / e-ink palette).
- **Format**: PNG (compressed with `pngcrush` or `optipng` if available).
